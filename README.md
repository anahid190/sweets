# Anahita — فروشگاه شکلات دست‌ساز لوکس

نسخه‌ی فارسی و راست‌چین فروشگاه آنلاین شکلات دست‌ساز با طراحی لوکس، کاتالوگ جعبه‌ها، جزئیات محصول، سبد خرید و فرم تسویه‌حساب نمایشی.

## اجرا

```bash
pnpm install
pnpm dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## ساختار اصلی

- `src/main.tsx` — رابط کاربری، داده‌های محصولات، سبد خرید و فرم تسویه‌حساب
- `src/styles.css` — طراحی بصری، رنگ‌ها و واکنش‌گرایی
- `public/manus-routes.json` — مسیرهای سایت
- `index.html` — عنوان و متادیتای فارسی
- `app.config.ts` — تنظیم لوگوی پروژه

تصاویر فعلی از فضای ذخیره‌سازی پروژه بارگذاری می‌شوند. برای اتصال به فروش واقعی، درگاه پرداخت و ثبت سفارش سمت سرور باید جداگانه اضافه شوند.
